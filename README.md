# ColorizeBot - Бот для раскрашивания фотографий
Нейросетевой бот для раскрашивания черно-белых фотографий с автоматической модерацией контента.

## Возможности

- Раскрашивание черно-белых фото нейросетью DeOldify
- Автоматическая модерация контента (NSFW + объекты)
- Добавление стильных рамок к результатам
- Мониторинг производительности в реальном времени
- Асинхронная обработка изображений

## Технологии

- **Aiogram** - Telegram Bot API
- **TensorFlow/Keras** - классификация изображений
- **DeOldify** - раскрашивание фото
- **NSFW Detector** - проверка безопасности
- **PIL/Pillow** - обработка изображений
- **psutil** - мониторинг системы

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```
2. Настройте параметры в коде:
```bash
IS_WATERMARK = True      # Добавлять рамки
CHECK_CONTENT = False    # Включить модерацию
CHECK_SCORE = 0.5        # Порог чувствительности
```
3. Запустите бота:
```bash
python main.py
```

Использование
1. Отправьте боту черно-белое фото  
2. Бот автоматически:  
* Проверит фото на безопасность  
* Раскрасит нейросетью  
* Добавит стильную рамку  
* Отправит результат    

## Безопасность
Бот проверяет изображения по двум уровням:
* NSFW Detector (Обнаружение неприемлемого контента)  
* MobileNetV2 (Блокировка 20+ категорий объектов)  

## Мониторинг
Система отслеживает в реальном времени:
* Время обработки изображений  
* Использование памяти  
* Статистику последних 1000 запросов  

## Настройки
Параметры модерации:
```bash
blocked_labels = [
    'warplane', 'butcher_shop', 'prison',
    'flagpole', 'military_uniform'  # и другие
]
```

Параметры обработки:
```bash
render_factor=35    # Качество раскрашивания (10-40)
LOGO_SCALE=0.5      # Размер водяных знаков
```

## Особенности обработки
Автоматический подбор рамок:  
* Вертикальные фото - вертикальная рамка  
* Горизонтальные фото - горизонтальная рамка  
* Квадратные фото - квадратная рамка  

Качество изображения:  
* Автоматическое ресайзинг с сохранением пропорций  
* Оптимизация для Telegram  
* Сохранение метаданных  

## Ограничения
* Максимальный размер: 20MB  
* Форматы: JPG, PNG, WEBP  
* Рекомендуется: четкие черно-белые фото  
* Время обработки: 10-30 секунд
